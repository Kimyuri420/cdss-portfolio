# 맥(脈)가이버 | Flutter 의료진·환자 앱

[← 전체 프로젝트 보기](../README.md)

관상동맥 협착 탐지 결과를 의료진의 업무와 환자의 정보 확인에 연결한 팀 모바일 프로젝트입니다. 의료진용·환자용 앱을 나누어 개발했으며, **저는 의료진 업무 화면과 환자 조회 흐름**을 맡았습니다.

## 내가 맡은 일

| 영역 | 구현 범위 |
| --- | --- |
| 환자 조회 | 의료진의 환자 검색과 정보 확인 |
| 소통·협진 | 채팅 및 답변 상태 관리, 비동기 협진 요청과 답변 |
| 일정·업무 | 캘린더, 의료진 To-do List |
| 기록 | 텍스트 메모와 음성 메모 |

의료진의 인증·AI 진단 화면, 환자 앱의 예약·건강관리 기능은 팀의 다른 담당 영역입니다. AI 모델 성능 역시 제 앱 작업의 성과로 묶지 않습니다.

## 설계와 사용 흐름

의료진이 이동 중에도 환자를 찾고, 협진 요청을 확인하고, 자신의 일정과 할 일을 관리하도록 화면을 연결했습니다. 채팅의 읽음·답변 상태를 구분하고, 메모를 텍스트와 음성으로 남기는 업무 흐름을 구성했습니다. 기능별 Flutter 모듈을 나누어 팀이 서로 다른 화면을 병행 개발했습니다.

## 한계와 다음 과제

최종 발표에서는 **채팅 실시간 반영 미지원**, 앱 재설치 시 정보 복원, HTTP에서 HTTPS/TLS로의 전환을 남은 과제로 기록했습니다. 따라서 실시간 채팅·완성된 배포 보안을 현재 구현 성과로 소개하지 않습니다.
