Medical Staff Approval Flow

STEP 01 의료진 회원가입 role = doctor
↓
STEP 02 미승인 계정 생성 is_approved = False
↓
STEP 03 관리자 승인 관리자 권한 확인
↓
STEP 04 승인 상태 변경 is_approved = True
↓
STEP 05 일반 로그인 허용 의료진 대시보드 연결
Authentication Logic Python 
# Simplified authentication example

user = authenticate(
    request,
    username=username,
    password=password
)

if user is not None:
    if user.is_approved:
        login(request, user)
    else:
        # 승인 대기 안내
        pass

Model Limitations
