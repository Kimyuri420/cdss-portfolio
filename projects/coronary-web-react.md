# 관상동맥 협착 탐지·XAI 판독 지원 웹 | React

[← 전체 프로젝트 보기](../README.md)

의료진이 관상동맥 조영 영상과 AI 분석 결과를 함께 살펴보는 팀 웹 프로젝트입니다. React 화면, Django API, FastAPI 모델 서버로 구성했습니다. **제가 맡은 범위는 메인 대시보드와 영상 뷰어 UI**입니다.

## 내가 맡은 일

| 화면 | 구현 범위 |
| --- | --- |
| 환자 대시보드 | 환자 ID 검색 결과를 개인 의료정보·과거력 카드로 표시 |
| 영상 뷰어 | 재생·일시정지, 0.5배속, 구간 반복, 확대 제어 |
| 화면 테마 | 판독 환경을 고려한 다크 모드 UI |

AI 모델 학습·서빙, 백엔드 DB, XAI 탭과 PDF 보고서 등은 팀의 다른 담당 영역입니다.

## 뷰어에서 다룬 문제

영상을 확대하거나 이동할 때 Bounding Box가 병변 위치에서 벗어나면 판독 화면의 의미가 달라집니다. 팀 발표에서는 **영상과 박스에 서로 다른 좌표·변환을 적용한 문제**를 상대 좌표와 공통 부모 컨테이너 방식으로 해결한 사례를 제시했습니다. 제 뷰어 작업 기록에도 확대·이동과 박스 좌표를 함께 관리하는 구조를 정리했습니다.

영상 URL, 재생 상태, 현재 시간과 FPS에서 계산한 프레임, Zoom/Pan, 박스·Heatmap 표시가 한 화면에서 일관되게 움직이도록 만드는 것이 UI의 핵심 과제였습니다. 브라우저에서 AVI가 재생되지 않아 MP4로 변환한 사례 등은 팀 전체 문제 해결 기록입니다.

## 한계

발표 자료에 따르면 데이터의 병원·장비·촬영 조건 다양성이 부족하고, 작은 병변과 흐릿한 프레임의 탐지 성능이 낮으며, 다기관 외부 검증은 수행하지 않았습니다. 웹 UI는 의료진 판단을 보조하는 화면입니다.
