01 / OVERVIEW

의료영상 판독을 위한
통합 업무 환경

환자 정보와 의료영상, AI 분석 결과를 하나의 의료진 중심 업무 흐름으로 연결합니다.

BACKGROUND

개발 배경

관상동맥 조영술 영상은 여러 영상과 프레임을 확인해야 하며, 작은 협착 의심 영역에 대한 반복적인 검토가 필요할 수 있습니다.

환자 정보, 의료영상, AI 분석 결과 및 판독 기록이 분리되어 있다면 의료진의 정보 확인 과정이 복잡해질 수 있습니다.

OBJECTIVE

프로젝트 목표

  • 관상동맥 협착 의심 영역 탐지
  • AI 분류 결과 및 시각적 설명 제공
  • 환자 중심 의료영상 조회
  • 의료진 판독 및 주석 인터페이스
  • 협진 및 결과 리포트 업무 연결
MY ROLE

개인 개발 범위

React 기반 의료진 Dashboard, 환자 검색 및 상세 화면, 의료영상 Viewer, Canvas 주석, 북마크 및 협진 화면의 인터페이스를 담당하였습니다.

팀원이 개발한 AI 모델과 서버 API를 활용하는 화면 구성 및 데이터 연결 과정에도 참여하였습니다.

PROJECT SCOPE

본 프로젝트는 교육용 의료 AI 프로토타입입니다. 실제 임상 적용, 의료적 유효성 및 안전성이 검증된 시스템은 아닙니다.

공통 좌표 및 확대 기준

Shared Transform JSX 
<div style={{
  transform:
    `translate(${x}px, ${y}px)
     scale(${scale})`
}}>
  <img src={imageUrl} />
  <canvas ref={overlayRef} />
</div>

팀의 좌표 정렬 구조를 설명하는 단순화 예시입니다.

RESPONSE STRUCTURE

AI 결과 데이터 구성

Example Response JSON 
{
  "classification": {

    "confidence": 0.8
  },
  "detection": {
    "bbox": {

      "y": 80,
      "width": 60,

TECHNICAL REVIEW

Bounding Box 높이 계산 오류 발견

+
OBSERVATION

AI 응답 정규화 코드의 일부 분기에서 높이를 y2 - y2로 계산하는 부분을 확인하였습니다.

CAUSE

동일한 좌표를 빼면 높이가 항상 0이 됩니다.

PROPOSAL

상단 및 하단 좌표의 차이를 사용하고 유효성 검사와 단위 테스트를 추가합니다.

Observed 
const height =
  Math.max(0, y2 - y2);
Proposed Fix 
const height =
  Math.max(0, y2 - y1);

코드 검토에서 발견한 개선 사항입니다. 실제 원본 프로젝트에 수정 사항을 적용하지 않았습니다.

10
TECHNICAL REVIEW

환자 변경 시 비동기 응답 일관성

+
OBSERVATION

환자 선택을 빠르게 변경하면 이전 환자의 요청이 나중에 완료될 가능성이 있습니다.

RISK

일부 요청 경로에서 이전 응답이 현재 화면에 반영될 수 있습니다.

PROPOSAL

AbortController와 요청 식별자를 활용하고 환자별 응답 검증 및 Object URL 정리를 강화합니다.

Patient A → Cancel A → Patient B

일부 취소 플래그는 기존 코드에 존재합니다. 전체 요청 경로에 대한 개선 및 검증은 향후 과제입니다.
