관상동맥 영상 판독 지원 웹

의료진이 환자를 찾고, 관상동맥 영상과 분석 결과를 한 화면에서 확인하는 웹 프로젝트입니다.

영상 뷰어 체험 환자 검색 데모
내 역할
환자 검색 대시보드와 영상 뷰어
팀·기간
5인 팀 · 개인 개발 3일
사용 기술
React · REST API

핵심 구현

  • 환자 검색 대시보드

    환자 ID 검색 결과와 의료정보·과거력을 확인하는 화면을 구현했습니다.

  • 영상 재생과 탐색

    재생·일시정지, 배속, 구간 반복을 연결해 원하는 영상 구간을 검토할 수 있게 했습니다.

  • 영상 확대와 화면 상태

    영상의 확대·이동과 병변 박스 좌표를 함께 관리하고 다크 모드를 구현했습니다.

데모의 영상과 환자 정보는 샘플입니다.

대표 구현 사례

영상과 병변 표시의 위치 맞추기

샘플 뷰어에서 체험하기
문제
영상을 확대하거나 옮길 때 병변 위치를 표시하는 상자도 영상과 함께 움직여야 했습니다.
구현
영상과 병변 표시를 같은 영역에 배치하고, 확대 배율과 이동 위치를 공통으로 적용했습니다.
예시
샘플 뷰어를 확대하거나 끌어서 옮겨보면, 병변 표시가 영상에 맞춰 움직이는 모습을 볼 수 있습니다.
