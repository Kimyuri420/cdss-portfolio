VENA

의료진 업무 지원 앱

의료진이 한 앱에서 환자를 조회하고, 협진에 답변하고, 일정과 메모를 관리할 수 있도록 만든 모바일 프로젝트입니다.

4인 팀 · 개인 개발 1주
사용 기술
Flutter · Dart · REST API · Provider

핵심 구현

  • 환자 조회와 대시보드

    환자 검색과 상세 정보 조회를 의료진 대시보드에 연결했습니다.

  • 채팅과 협진

    의료진 간 메시지와 협진 요청·답변 상태를 확인할 수 있는 화면을 구현했습니다.

  • 일정과 기록

    캘린더, 할 일, 텍스트·음성 메모를 의료진 화면에서 관리하도록 구현했습니다.

웹 데모는 가상 데이터로 앱의 동작을 재현합니다.
